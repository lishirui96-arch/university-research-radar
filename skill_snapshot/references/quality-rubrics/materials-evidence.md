# 材料研究证据质量量表

本量表评价一项成果对材料性能、机理、器件表现和转化阶段的支持强度，不评价作者或高校。等级按已核验的最高证据层级记录；元数据、新闻稿或推断不能替代正文证据。

## 通用等级

| 等级 | 含义 | 最低证据要求 |
|---|---|---|
| L0 | 仅有元数据 | 只有题名、摘要、关键词或数据库记录，未核验方法和结果。 |
| L1 | 计算预测 | 有模型、模拟或高通量预测，但没有对应材料的实验制备与验证。 |
| L2 | 合成与基础表征 | 已制备材料，并有基本组成、结构或性能表征；对照、重复或工况有限。 |
| L3 | 机理与稳健对照 | 有合理对照、重复性、误差/统计信息或多方法交叉表征，并对机制给出直接证据。 |
| L4 | 相关条件下的器件或系统验证 | 在与目标用途相关的器件、系统、载量、尺寸、环境或工况下验证。 |
| L5 | 耐久、放大或标准化测试 | 有长期/循环稳定性、批次复现、面积/质量放大、标准方法或第三方测试中的至少一类强证据。 |
| L6 | 中试、标准或工业场景验证 | 有中试线、实际工况、标准认证、工业合作验证或可审计的规模化制造证据。 |

L6 不自动等于已商业化。商业化还需独立核验量产、销售、客户采用或监管批准等证据，并单列状态与来源。

同一论文可对不同主张给出不同等级。例如材料合成可达 L3，而器件寿命只有 L2。报告必须注明等级对应的具体主张。

## 领域检查清单

### 电池材料

- 活性物质载量、面容量、电极密度、电解液用量、N/P 比和温度是否接近目标应用。
- 半电池与全电池、扣式与软包/圆柱器件是否分开。
- 容量、倍率、库仑效率、循环寿命和安全性是否同时给出测试条件。
- 是否有批次重复、失效分析及与合理基准材料的同条件对照。

### 光伏材料

- 报告稳态效率还是扫描效率，是否有独立认证。
- 器件有效面积、遮光掩模、组件面积和串联结构是否明确。
- 稳定性是否注明封装、光照、湿度、温度、偏压和测试协议。
- 含铅、溶剂、封装和规模化制备问题是否被纳入转化判断。

### 催化材料

- 催化剂载量、活性面积归一化方式、电解液/反应气、温压和传质条件是否明确。
- 活性、选择性、法拉第效率、能效和耐久性是否在同一条件下报告。
- 是否排除污染、基底、粘结剂或反应器带来的伪活性。
- 产物定量、同位素验证和反应前后结构证据是否支持机理主张。

### 结构合金

- 成分、原料、加工路线、热处理、组织和试样方向是否完整。
- 强度、塑性、韧性、疲劳、蠕变、腐蚀等性能的标准、温度和应变率是否可比。
- 是否有足够试样数、误差、批次和缺陷统计。
- 小试样或微柱结果不得直接等同于构件级性能；增材制造须记录孔隙、残余应力和后处理。

### 聚合物与分离膜

- 分子量、交联度、添加剂、厚度、形态和制备批次是否明确。
- 自修复/可降解测试的温湿度、介质、时间、循环和性能保持是否明确。
- 膜的渗透性与选择性是否成对报告，并注明进料组成、压力、温度和面积。
- 是否有抗污染、溶胀、塑化、老化和长期连续运行证据。

### 人工智能材料发现

- 数据集来源、许可、去重、时间切分、泄漏检查和适用域是否透明。
- 是否与有竞争力的基线比较，并报告外部测试、不确定性和失败案例。
- 预测候选是否经过独立计算复核、实验合成和性能验证。
- 自动实验闭环是否真实运行，命中率、实验预算和负结果是否披露。

## 可比性与评分规则

- 不比较测试协议不兼容的“最高性能”数字。若载量、面积、温度、压力、介质、循环定义、归一化方式或器件结构不同，标为“不可直接比较”。
- 优先构造同条件对照表；无法统一时，展示原始条件和范围，不强行归一化。
- 期刊声誉、引用数和高校名气只能作为辅助信号，不能替代证据等级。
- 预印本可以评级，但必须标明未同行评审；专利实施例按披露内容评级，不因授权自动提高等级。
- 缺少全文时最高为 L0，除非其他可审计来源提供了足够的方法与结果细节。
