# 材料科学领域配置

本配置适用于材料科学、新材料以及以材料成分、结构、制备、性能或服役行为为核心的交叉研究。它补充主技能的通用规则；发生冲突时，仅在本次材料扫描中采用本配置。

## 范围定义

用四个相互关联的维度组织研究内容，而不是只按材料名称计数：

1. 材料族：金属、陶瓷、聚合物、复合材料、半导体、能源材料、生物材料、二维材料、多孔材料等。
2. 技术主题：合成、加工、表征、计算设计、界面调控、器件集成、回收与再制造等。
3. 性能问题：能量密度、离子/电子传输、选择性、稳定性、强韧性、耐蚀性、热管理、可降解性等。
4. 应用场景：电池、光伏、催化、芯片、航空航天、医疗、建筑、分离净化、低碳制造等。

每个可报告主题至少包含“材料或材料族”锚点，并尽量同时包含制备/工艺、性能问题、应用场景中的两项。禁止仅用 `material`、`materials science`、`新材料` 等泛词检索后直接生成热点排名。

## 检索与分类

- 先用主题词表构建中英文种子检索式，再用观察期样本中的作者关键词、主题词和高频短语扩展候选词。
- 对简称、多义词和跨学科术语增加材料锚点或应用锚点。例如 `HEA`、`COF`、`interface`、`foundation model` 不可脱离上下文单独检索。
- 主题词命中只表示候选归类；最终归类需结合标题、摘要、关键词、期刊范围和代表论文人工抽检。
- 一篇论文可以多标签归类，但主主题只能有一个；记录多标签规则，防止重复计入总量。
- 词表外的新簇先标记为“候选新主题”，达到最小样本量且经代表论文校验后再命名。
- 中国与全球对照使用同一概念定义，但允许同义词和数据库字段不同；分别统计后再映射。

## 热点与趋势参数

沿用主技能的规模、增速、加速度、课题组广度、机构扩散、质量、产业关联和置信度指标，并增加以下材料领域约束：

- 热度不能只由论文量决定。至少同时展示研究广度、证据等级分布和测试条件可比性。
- “升温”必须有历史基线；新出现的小样本主题以候选信号呈现，不直接列为成熟热点。
- 产业关联可由专利、基金、标准、放大制备、长期稳定性和真实工况验证增强，但不能由单一企业合作或新闻稿替代。
- 建议综合排序时，规模与增速合计不超过 40%，证据质量与可复现性不低于 25%，其余分配给扩散度、产业关联和数据置信度；必须同时给出分项值。
- 计算/AI 预测主题与实验验证主题分列证据等级，不能因预测材料数量大而放大热点规模。

## 材料领域输出

除通用报告要求外，至少提供：

- 热点主题表：材料族、技术主题、性能问题、应用场景、规模、变化、证据等级、代表高校/课题组和代表成果。
- 上升方向表：基线、观察期、增速/加速度、扩散情况、小样本警告和判断置信度。
- 中外对照：相同主题下的研究重点、材料体系、验证深度和应用阶段差异。
- 性能证据表：关键指标、测试条件、对照基准、样本/器件尺度、耐久性和是否可直接比较。
- 转化信号表：论文、专利、基金、标准或中试之间的明确关联及关联置信度。

报告中把“论文热点”“高质量验证热点”“转化活跃方向”分开排序，避免把发文活跃等同于技术成熟。
