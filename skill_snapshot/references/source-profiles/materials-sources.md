# 材料科学数据源配置

本配置规定各类来源在材料热点扫描中的角色。遵守主技能的许可、访问、溯源和覆盖披露规则；不可访问的来源只报告缺口，不以推测补齐。

## 学术论文与预印本

| 来源 | 主要角色 | 使用限制与核验 |
|---|---|---|
| OpenAlex | 大范围发现论文、机构、作者、主题和引用关系 | 主题标签不替代材料词表；抽检机构归一化和 DOI。 |
| Crossref | DOI、题名、期刊、日期和版本核验 | 摘要与机构覆盖不完整，不单独承担主题统计。 |
| Web of Science / Scopus | 在合法订阅和导出权限下补充引文、作者关键词、机构与学科字段 | 记录数据库版本、索引范围、检索式和导出上限；不得暗示公开可复现。 |
| CNKI / 万方 | 补充中文期刊、学位论文和国内项目线索 | 在合法访问范围内使用；与英文版本、重复发表和学位论文去重。 |
| ChemRxiv / arXiv | 捕捉前沿预印本和计算材料方向 | 与正式发表版本关联但分开计数；明确未同行评审。 |
| 期刊官网与出版社页面 | 核验摘要、补充信息、发表状态和更正/撤稿 | 不绕过付费墙；只引用可合法访问的内容。 |

推荐组合为一个覆盖源加一个元数据核验源。若要声称“全景”或进行高校排名，应在许可允许时加入 WoS/Scopus 或等价的稳定索引，并披露中文文献和会议/预印本覆盖差异。

## 专利

优先使用 CNIPA、WIPO Patentscope、EPO Espacenet；在授权条件下可使用 Lens。Google Patents 仅用于有针对性的核验和族信息补充，不作为无说明的唯一统计源。

检索时将关键词与 CPC/IPC 分类结合，并根据细分主题扩展：

- `H01M`：电池、燃料电池及相关材料。
- `C22C`：合金及其组成。
- `C08`：有机高分子化合物及其制备或加工。
- `C01B`：非金属元素及其化合物等无机材料。
- `C04B`：水泥、陶瓷、耐火材料及相关组合物。
- `B82Y`：纳米结构的特定用途或测量制造。

分类号仅是检索入口，不能替代权利要求与实施例核验。按专利族去重，区分申请、公开、授权、失效和转让状态；高校申请人、发明人和课题组之间的对应关系需单独给出证据。

## 基金与项目

中国侧优先核验国家自然科学基金委员会公开信息、科技部及国家重点研发计划、教育部和省级科技计划、高校官方项目页面。全球对照可使用欧盟 CORDIS、美国 NSF Award Search、美国能源部及相关实验室公开项目库。

基金金额、起止时间、项目类型和牵头/参与单位必须来自官方记录或可审计数据。立项代表资源投入和政策信号，不代表成果已实现。

## 高校与课题组官方来源

高校、学院、实验室、教师主页、成果库和官方新闻用于核验课题组归属、设备平台、项目和转化事件。新闻稿只能支持其明确陈述的事件，不能替代论文方法、性能或商业化证据。

## 跨来源关联

论文、专利、基金、标准和中试事件之间只在存在明确标识或强匹配证据时关联：

- 高置信度：DOI、专利号、基金号、项目编号或标准号被另一来源明确引用。
- 中置信度：作者/发明人、高校/企业、技术主题和时间窗口同时高度一致，并经人工复核。
- 低置信度：只有相似题名、关键词或机构；保留为候选线索，不写成确定关联。

保存原始标识符、来源链接、检索日期、匹配规则和置信度。不得以同名作者或同一高校作为唯一关联依据。

## 覆盖与来源质量

- 每一数据源记录检索式、字段、时间范围、返回量、导出限制、更新时间和访问方式。
- 分别报告论文、预印本、专利、基金和官方网页的覆盖，不把不同文献类型混成同一产出量。
- DOI、专利族、基金号和机构名称分别规范化；所有自动匹配保留人工抽检样本。
- 数据库缺失摘要、机构或引用时降低主题和趋势置信度，不用其他字段静默填补。
- 来源之间数值冲突时保留原值和采集时间，说明采用哪一值及理由。
